Позволяет получать серии и озвучки напрямую из Alloha по kp_id, даже если они отсутствуют в каталоге видео Yummy.
Папка на сервере Jellyfin для основного списка и ручных релизов. Плагин создаёт Series/Season 01/*.strm и *.nfo. Добавьте эту папку в медиатеку Jellyfin.
Часть названия озвучки для выбора приоритета. Несколько вариантов разделяйте символом |.
При обновлении создаются отдельные файлы для каждой озвучки, например S01E01 - AniLibria.strm, со ссылкой на выбранную озвучку.
По умолчанию: предупреждения (Warning). Для диагностики выберите информационные сообщения (Information) или более подробный уровень.
Записывает подробности HTTP-запросов и ответов Kodik. Включайте только для диагностики: журнал может быстро расти.
Показывает длительность этапов обновления, операции с файлами и проверки Kodik. Помогает выяснить причину медленного обновления.
Аниме из основного списка сохраняются в основную папку. Для обоих списков используется один аккаунт Yummy: подключённый в разделе «Аккаунт Yummy».
Действует для обоих списков, каждый в своей папке. Удаляются только подтверждённые файлы плагина после успешного получения соответствующего списка. Ручные релизы, неизвестные и изменённые файлы сохраняются; при ошибке API удаление не выполняется.
Вторая папка обновляется отдельной задачей YummyKodik: second library refresh — по умолчанию раз в сутки. Расписание меняется в задачах Jellyfin. Ручные релизы добавляются только в основную папку. Настройки качества и озвучек общие.
Укажите отдельную папку на сервере Jellyfin, не совпадающую с основной: папки не должны быть вложены друг в друга. Добавьте её во вторую медиатеку Jellyfin.
Перезагрузка отменяет несохранённые изменения.
